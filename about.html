Sobre MLBB Collection

MLBB Collection es un proyecto académico creado para presentar información relacionada con Mobile Legends: Bang Bang de una manera sencilla y organizada.

El sitio reúne información sobre héroes, skins y otros elementos relacionados con el juego.

Objetivo del proyecto

El objetivo es desarrollar un sitio web utilizando tecnologías básicas de desarrollo web y aplicar conceptos de estructura, navegación, tablas, formularios, imágenes y contenido multimedia.

Tecnologías utilizadas

Tecnología Uso
HTML5 Creación de la estructura de las páginas.
CSS3 Diseño, colores, tamaños y distribución.
JavaScript Interactividad y funcionamiento del formulario.
